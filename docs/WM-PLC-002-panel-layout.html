ELECTRICAL CONTROL PANEL — GENERAL ARRANGEMENT (แผ่นที่ 1: ผังจัดวางอุปกรณ์)

ตู้ควบคุม W440 × H610 × D230 มม. — วาดมุมมองด้านหน้า (เปิดฝาตู้) ตามสัดส่วนจริง (NTS, มาตราส่วนประมาณ 1:2.6) แสดงตำแหน่งราง DIN แต่ละแถวและช่องว่างที่เหลือสำหรับเดินสาย/ขยายในอนาคต

สัญลักษณ์ราง DIN (ROW LEGEND)
แถว 1 — ทางเข้าไฟ / ป้องกันวงจร / แหล่งจ่าย
แถว 2–3 — PLC LOGO! + AM2 ×6 + Ethernet switch
แถว 4 — Terminal จ่ายไฟ DC/PE (ภายในตู้)
แถว 5 — Terminal สายเซนเซอร์ภาคสนาม (ออกนอกตู้)
พื้นที่ประ = ว่างสำหรับขยาย/เผื่ออนาคต
หมายเหตุขนาดอุปกรณ์ที่ใช้คำนวณผัง
  • LOGO!Power 24V/2.5A (6EP3332-6SB00-0AY0): กว้าง 54mm — ยืนยันจากดาต้าชีทจริง
  • LOGO! base: กว้าง 71.5mm — ยืนยันจากดาต้าชีทจริง
  • LOGO! AM2: กว้าง 36mm (2 modular width) — ยืนยันจากดาต้าชีทจริง
  • MCB 2P 6A, Fuse 32A, Ethernet switch, terminal pitch: เป็นค่าประมาณทั่วไป ยังไม่ยืนยันกับรุ่นที่จะซื้อจริง — ต้องตรวจสอบก่อนสั่งราง DIN/เจาะแผ่นเพลท
  • สรุป: อุปกรณ์ทั้งหมดใช้ความกว้างรางจริงประมาณ 165mm ต่อแถว จากที่มีให้ 440mm — เหลือพื้นที่มากกว่าครึ่ง ต่อแถว เพียงพอสบายๆ

สรุปผล
  • ตู้ 440×610×230mm เพียงพอ — ทุกแถวใช้ความกว้างจริงไม่เกิน ~180mm จากที่มีให้ ~400mm (หลังหักระยะขอบราง) เหลือพื้นที่มากกว่าครึ่งทุกแถว
  • ความสูง 610mm แบ่งได้ 5 แถว + พื้นที่ว่างด้านบน/ล่างสำหรับสายเข้า-ออกและเผื่อขยาย โดยไม่แน่นเกินไป
  • ความลึก 230mm เพียงพอสำหรับอุปกรณ์ DIN rail มาตรฐานทั่วไป (ตัวอุปกรณ์ลึกไม่เกิน ~110mm) + wireway + ระยะห่างจากฝาตู้ — ไม่มีปัญหาเรื่องความลึก
  • รายการที่ยังไม่ยืนยัน: ขนาดจริงของ MCB 2P 6A, Fuse 32A holder, Ethernet switch, และ terminal block รุ่นที่จะซื้อจริง — ตัวเลขในตารางเป็นค่าประมาณอุตสาหกรรมทั่วไป ให้ตรวจกับสเปกจริงก่อนสั่งของ/เจาะแผ่นเพลทติดตั้ง
  • Fuse F1 (32A) วางไว้เป็นตัวตัดวงจรหลักที่ทางเข้า (เผื่อขยายวงจรอื่นในอนาคต) ส่วน MCB 2P 6A (Q1) เป็นตัวป้องกันเฉพาะวงจร LOGO!Power — ถ้าตั้งใจให้ Fuse ทำหน้าที่อื่น (เช่น อยู่ฝั่ง DC) แจ้งได้ จะแก้ผังให้ตรง
